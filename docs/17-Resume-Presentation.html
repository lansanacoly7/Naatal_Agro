1. L'idée en une phrase

Naatal Agro est un copilote de poche pour l'agriculteur : sur son téléphone, il voit la météo de son champ, les prix des marchés, le suivi de ses cultures, et il peut poser des questions à un assistant intelligent.

Quel problème on règle ?

  • Il manque d'informations au même endroit : météo d'un côté, prix de l'autre.
  • On décide surtout « à l'habitude », sans outil pour savoir si c'est le bon moment.
  • On perd de l'argent sans le voir : vendre trop tôt, au mauvais marché, au mauvais prix.
  • Les outils existants sont trop compliqués ou pas adaptés à la réalité locale.

Notre réponse : un seul écran simple, en français, pensé pour le Sénégal, qui accompagne l'agriculteur « du semis jusqu'à la vente ».

Exemple : l'agriculteur ouvre l'app → elle demande les prix au serveur → le serveur va les chercher dans la base de données → il les renvoie → l'écran s'affiche.

Important : chaque partie est rangée dans son propre « tiroir » (cultures, marchés, météo, IA…). Si on modifie l'une, on ne casse pas les autres. C'est ce qu'on appelle une application modulaire.

4. L'assistant intelligent : pourquoi on peut lui faire confiance

Une IA peut se tromper et inventer. Nous avons donc mis des garde-fous :

  1. Il répond d'abord avec nos fiches techniques sur les cultures (oignon, tomate, arachide, mil, riz), écrites à partir de sources sérieuses : ministère de l'agriculture, ISRA, FAO, etc.
  2. Il cite ses sources dans la réponse.
  3. Si l'information n'existe pas dans nos fiches, il le dit au lieu d'inventer.
  4. Une nouvelle information n'entre dans la base que si elle vient d'un site officiel et après validation.
  5. Limite d'utilisation : 30 questions par heure et par personne, pour éviter les abus et les coûts.
  6. Les clés secrètes des IA restent sur le serveur, jamais dans le téléphone.

Avec une photo, l'assistant peut aussi aider à reconnaître une maladie de plante.

5. La sécurité, en simple

  • Les mots de passe ne sont jamais stockés en clair : ils sont transformés pour être illisibles.
  • La connexion donne un « badge » temporaire (il expire, on peut l'annuler à la déconnexion). Il est rangé dans le coffre sécurisé du téléphone.
  • Chacun ne voit que ses propres données : un agriculteur ne peut pas lire les cultures, le stock ou les finances d'un autre.
  • Limites anti-piratage : trop d'essais de connexion en peu de temps = bloqué quelques instants.
  • Protection des données personnelles : on demande le consentement à l'inscription, l'utilisateur peut télécharger ses données et supprimer son compte.
  • Mode hors ligne : si le réseau est mauvais, l'application affiche « hors ligne » et garde ce qui a déjà été chargé.

6. Où on en est, honnêtement

Mieux vaut le dire nous-mêmes que de se faire surprendre par le prof.

✅ Ce qui est solide

  • Le serveur fonctionne et est testé : 175 tests automatiques passent (ils vérifient que tout marche comme prévu).
  • L'application mobile passe le contrôle de qualité du code sans aucune erreur.
  • Connexion, déconnexion, profil, cultures, marchés, météo, stock, finances, IA, notifications côté serveur : en place.
  • Une chaîne automatique (CI) relance les tests à chaque modification.

⚠️ Ce qui n'est pas encore fini

  • Certains écrans affichent des données d'exemple (fiche produit, comparaison de marchés, calendrier des cultures) et pas encore les vraies données du serveur.
  • La vérification du code reçu par SMS est simulée à l'inscription : l'écran existe mais ne vérifie pas vraiment.
  • Le site web est seulement une démonstration.
  • Les notifications sur téléphone : le serveur est prêt, mais l'application ne les reçoit pas encore.
  • Pas encore en ligne : il manque la connexion sécurisée (https) et la surveillance du serveur avant un vrai lancement.

C'est normal pour un projet de fin de formation : le cœur fonctionne, la finition et la mise en ligne restent à faire.

7. Questions que le prof peut poser

Pourquoi ce projet ? À qui ça sert ?

Aux agriculteurs du Sénégal qui n'ont pas d'outil simple pour décider. Au lieu de jongler entre plusieurs sources, ils ont tout dans une seule application.

En quoi c'est différent d'une simple application météo ?

On ne donne pas juste la météo : on relie la météo, les cultures, les prix et un assistant, pour aider à décider (quand vendre, quoi faire cette semaine).

Pourquoi ces technologies (Flutter, Django…) ?

Flutter : un seul code pour Android et iPhone. Django : solide, sécurisé, rapide à développer. Gemini et Groq : deux IA qui se relaient si l'une est en panne.

Que se passe-t-il si l'IA se trompe ?

Elle répond d'abord avec nos fiches sourcées, cite ses sources et admet quand elle ne sait pas. Une information nouvelle n'est acceptée que depuis un site officiel, après validation.

Et s'il n'y a pas d'internet ?

L'application le signale et garde les données déjà chargées. Elle se resynchronise dès que le réseau revient. C'est important au Sénégal en zone rurale.

Comment protégez-vous les données ?

Mots de passe illisibles, badge de connexion temporaire rangé dans le coffre du téléphone, chacun ne voit que ses données, limites anti-piratage, consentement, export et suppression du compte.

Comment savez-vous que ça marche ?

175 tests automatiques côté serveur, des tests côté application, et une vérification automatique à chaque modification du code.

Qu'est-ce qui reste à faire ?

Brancher les écrans qui affichent encore des exemples sur les vraies données, vérifier réellement le code SMS, recevoir les notifications, finir le site web, puis la mise en ligne sécurisée.

Comment vous êtes-vous organisés à quatre ?

Chacun a travaillé sur sa branche dans Git (outil qui garde l'historique et évite d'écraser le travail des autres). Les modifications sont relues avant d'être fusionnées. Tout le monde doit pouvoir expliquer l'ensemble du projet.

8. À retenir avant demain

  • Naatal Agro = un copilote agricole sur téléphone : météo + marchés + cultures + assistant.
  • Trois blocs : téléphone (ce qu'on voit), serveur (le cerveau), base de données (la mémoire).
  • L'IA est encadrée : sources citées, pas d'invention, limites d'usage.
  • Les données de chacun sont privées et protégées.
  • On est honnêtes sur ce qui reste à finir.
